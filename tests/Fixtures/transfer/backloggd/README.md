Backloggd has no export of its own; these are the two files community tools
save. `toolkittd.csv` has the header and value spelling the Toolkittd add-on
(1.1.1) writes: its column list, booleans as true/false and the CRLF lines of
Papa Parse. `backloggdexporter.csv` is the `Title,Rating` file of
Medpus/BackloggdExporter, stars with one decimal, blank when unrated. The
games and their values are made up.
