Shapes built from Kavita's own API schema, not captured live
(Kareadita/Kavita@7f97cdc, `openapi.json`, v0.9.1.24): `UserDto` for
`GET /api/Account`, `LibraryDto` for `GET /api/Library/libraries` (one library
of each type), and `SeriesDto` for `POST /api/Series/all-v2`: `series.json` the
series begun, `series-publication-over.json` those of them whose publication is
over. Titles and the MyAnimeList, ComicVine and Hardcover ids
are the real series'; pages, reading, ratings and dates are made up.
