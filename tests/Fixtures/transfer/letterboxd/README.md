The shape of a Letterboxd data export (Settings → Import & Export → Export
your data), taken from a real export published on GitHub: the file names,
headers, `Rewatch` values, the `boxd.it` address of a diary entry (its own,
not the film's) and the list file with its `Letterboxd list export v7`
preamble. The rows are made up. `deleted/` stands for the entries a user
removed, which the export keeps beside the library.
