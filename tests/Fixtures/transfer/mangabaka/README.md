The shape of `GET /v2/my/library` from MangaBaka's own API schema
(mangabaka.org/api.json, read 2026-11-21; the default lean series): each
entry with its series and the lists it is on, and the pagination block;
`profile.json` is `GET /v1/my/profile` for a personal access token.
Titles and MyAnimeList ids are the real series'; ratings, progress, dates
and list names are made up. No response here was captured from the live API.
