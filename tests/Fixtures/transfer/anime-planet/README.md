Anime-Planet's JSON list export: the user and `entries`, one per title,
with `name`, `status` (manga: read, reading, stalled, want to read,
dropped, won't read; anime: watched, watching, want to watch…), `started`
and `completed` as "YYYY-MM-DD HH:MM:SS" or null, `rating` in half stars
(0 unrated), `times`, and `ch`/`vol` for manga, `eps` for anime. The keys
are the ones community converters read from real exports; the `export`
block is not read. Titles and values are made up.
