`gameDB.csv` as GOG-Galaxy-Export-Script writes it: tab-separated, UTF-8,
a list value (`platformList`) joined by the separator itself and quoted,
the play time in minutes (`gameMins`), the user's stars (`myRating`), a
release date as `YYYY-MM-DD`, `isHidden` as `True`/`False`. Only the columns
the import reads are here; the script writes more. The games and their
values are made up.
